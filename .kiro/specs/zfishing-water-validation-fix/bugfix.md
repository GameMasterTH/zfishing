# Bugfix Requirements Document

## Introduction

ผู้เล่นสามารถตกปลาได้ในตำแหน่งที่ไม่ได้อยู่ใกล้น้ำจริง ตราบใดที่ยังยืนอยู่ภายใน radius แนวนอน (2D) ของ fishing zone

พฤติกรรมที่คาดหวังคือ ต้อง "อยู่ใกล้น้ำจริง" เท่านั้นจึงจะขว้างเบ็ด/ตกปลาได้ แต่ปัจจุบันการตรวจว่าอยู่ใกล้น้ำ (`nearWater()`) ถูกเรียกเฉพาะตอนหยิบเบ็ดใช้งานครั้งแรก (`startRodUse` ใน `client/main.lua`) เท่านั้น ไม่ได้ตรวจซ้ำ ณ จังหวะที่ขว้างเบ็ดจริง ทำให้ผู้เล่นที่หยิบเบ็ดใกล้น้ำ (ผ่าน gate) แล้วเดินออกไปยืนบนพื้นดินภายใน zone radius สามารถขว้างเบ็ดได้ทั้งที่ไม่ได้อยู่ใกล้น้ำ

**ผลกระทบ:** ผู้เล่นตกปลาได้จากบนบก/ในที่ที่ไม่มีน้ำ ทำให้ระบบตกปลาไม่สมจริงและเป็นช่องโหว่ที่ implementation ไม่ตรงเจตนา

**ขอบเขตการแก้ไข (ยืนยันกับผู้ใช้แล้ว):**
- ตรวจสอบความใกล้น้ำ **ณ จังหวะ cast เท่านั้น** ไม่ตรวจซ้ำแบบ real-time ระหว่างที่รอปลากิน/สู้ปลา
- แก้แบบ **client-side gate** โดยเพิ่มการเรียก `nearWater()` ซ้ำก่อนเริ่ม cast ไม่แตะ logic ฝั่ง server
- **หมายเหตุขีดจำกัดที่ยังไม่ครอบคลุม:** การตรวจน้ำแบบ authoritative ฝั่ง server ทำได้ยากเพราะ `TestProbeAgainstWater` / `GetWaterHeight` เป็น client-side natives โดยหลัก ดังนั้น client ที่ถูกดัดแปลง (modded) ยังมีโอกาส bypass การตรวจน้ำได้ ประเด็นนี้ถือเป็นข้อจำกัดที่รับทราบและอยู่นอกขอบเขตของ bugfix นี้ (ควร revisit ภายหลังหากพบวิธีตรวจฝั่ง server ที่เชื่อถือได้)

## Bug Analysis

### Current Behavior (Defect)

พฤติกรรมที่เกิดขึ้นปัจจุบันเมื่อผู้เล่นหยิบเบ็ดใกล้น้ำแล้วเดินออกไปยืนบนพื้นที่ไม่ใช่น้ำแต่ยังอยู่ใน zone radius

1.1 WHEN ผู้เล่นหยิบเบ็ดใกล้น้ำสำเร็จ (ผ่าน gate) แล้วเดินออกไปยืนบนพื้นดินที่ยังอยู่ภายใน zone radius (2D) THEN the system อนุญาตให้ขว้างเบ็ดและเริ่มตกปลาได้สำเร็จ ทั้งที่ผู้เล่นไม่ได้อยู่ใกล้น้ำจริง

1.2 WHEN ผู้เล่นกดขว้างเบ็ด (charge/release) ในตำแหน่งที่ไม่ได้อยู่ใกล้น้ำ THEN the system ไม่ตรวจสอบความใกล้น้ำซ้ำ ณ จังหวะ cast และดำเนินการ cast ต่อโดยไม่มีการปฏิเสธ

### Expected Behavior (Correct)

พฤติกรรมที่ถูกต้องคือ ต้องอยู่ใกล้น้ำจริง ณ จังหวะ cast เท่านั้นจึงจะขว้างเบ็ดได้

2.1 WHEN ผู้เล่นหยิบเบ็ดใกล้น้ำสำเร็จ แล้วเดินออกไปยืนบนพื้นดินที่ยังอยู่ภายใน zone radius (2D) และพยายามขว้างเบ็ด THEN the system SHALL ปฏิเสธการ cast และไม่เริ่ม session ตกปลา

2.2 WHEN ผู้เล่นพยายามขว้างเบ็ดในตำแหน่งที่ไม่ได้อยู่ใกล้น้ำจริง THEN the system SHALL แจ้งเตือนด้วยข้อความ `need_water` และยกเลิก/จบการทำงานอย่างสะอาด (ไม่ค้างอยู่ในสถานะถือเบ็ด)

### Unchanged Behavior (Regression Prevention)

พฤติกรรมเดิมที่ต้องคงไว้ไม่ให้พังหลังการแก้ไข

3.1 WHEN ผู้เล่นอยู่ใกล้น้ำจริงและอยู่ภายใน zone ที่มีปลา แล้วขว้างเบ็ด THEN the system SHALL CONTINUE TO เริ่ม session ตกปลาและ cast ได้ตามปกติ

3.2 WHEN ผู้เล่นหยิบเบ็ดขึ้นมาใช้งานในตำแหน่งที่ไม่ได้อยู่ใกล้น้ำ THEN the system SHALL CONTINUE TO ปฏิเสธการหยิบเบ็ดพร้อมแจ้งเตือน `need_water` เหมือนเดิม

3.3 WHEN ผู้เล่นหยิบเบ็ดในตำแหน่งที่ไม่มี zone ใดครอบคลุม (และ `Config.RequireZone` เปิดอยู่) THEN the system SHALL CONTINUE TO ปฏิเสธพร้อมแจ้งเตือน `no_fish_here` เหมือนเดิม

3.4 WHEN ผู้เล่นขว้างเบ็ดใกล้น้ำจริงตามปกติ THEN the system SHALL CONTINUE TO คำนวณ power ของการขว้าง, spawn ทุ่น, และดำเนินกลไก bite/hook/reel ได้เหมือนเดิม

3.5 WHEN ผู้เล่นกด cancel (X) ในทุกเฟส THEN the system SHALL CONTINUE TO ยกเลิกและคืนสถานะได้ตามปกติ
